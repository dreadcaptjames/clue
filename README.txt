THE CLUE LEDGER — Interactive Detective Sheet

A touch-friendly, no-account replacement for the six-column Clue note sheet.
The sheet has 6 suspects, 6 weapons, and 9 rooms, exactly as on the uploaded 2023 Hasbro sheet.

HOW IT WORKS
- Enter up to six player names across the top.
- Choose × (eliminated), ✓ (confirmed), ? (uncertain), or Erase.
- Tap a square to write the selected mark. Tap it again to remove the mark.
- Write extra deductions in Field Notes.
- All notes and player names save automatically in the browser on the current device.
- Use New game for a fresh sheet; the dropdown switches between saved games.
- Game options includes Rename, Clear, Delete, Export backup, and Import backup.

USING THE SINGLE HTML FILE
Clue_Detective_Pad.html is fully self-contained and works offline in a browser or HTML
viewer that actually runs JavaScript. On iPad, simply tapping a .html file in the
Apple Files app may show a NONINTERACTIVE Quick Look preview. This is an iPadOS
limitation, not a problem with the sheet. Use a trusted HTML-running viewer or
publish the included PWA folder to a static HTTPS host (such as GitHub Pages).

BEST IPAD EXPERIENCE: INSTALLABLE OFFLINE WEB APP
1. Put the contents of this ZIP (index.html, manifest.webmanifest, service-worker.js,
   and both icon PNG files) at the ROOT of a GitHub Pages repository or other HTTPS site.
2. Open the website in Safari on the iPad.
3. Tap Share > Add to Home Screen, enable Open as Web App, then tap Add.
4. Open its new icon from the Home Screen. The app works offline after it has
   opened and cached successfully once while connected to the internet.

IMPORTANT ABOUT SAVES
Marks are stored in browser localStorage per website/app context. Browser storage
can be cleared; the Files app preview or some third-party viewers might not preserve
localStorage. Use Game options > Export all games (backup) for safety, especially
before switching the way the app is opened, clearing browser data, or changing iPads.
